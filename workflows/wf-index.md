*Created 2026-09-20, per the Workflows Folder Spec v1.0 (§6). Destination:
`Historiotheque/Historiotheque/workflows/wf-index.md` — paste there when the
`workflows/` folder is seeded.*

**TBD** = to be determined — fill it in as each workflow is written, run, or revised.

## How to add a row

1. Take the next sequential ID for the year (`WF-YYYY-NNN`).
2. Write the workflow file (`wf-YYYY-NNN-<slug>.md`) per the spec's file format.
3. Add one row below: ID, title, status, version, last run date, file name.

## Status values

Per the spec: `draft` (written, not yet in force) · `active` (in force) ·
`deprecated` (superseded — never delete the row; deprecate it).

## Notes

- IDs are sequential within the year and stable forever; if a title's slug changes,
  the ID does not.
- "Last run" is the date the workflow was last executed, `YYYY-MM-DD`. A workflow
  that has never run keeps TBD.
- Running a workflow is logged per the Studio Log Spec, with the workflow's ID in the
  log frontmatter (`workflow: WF-YYYY-NNN`); the dated line goes here, in this index.
