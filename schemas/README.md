# Schemas

The classification structures of the Art Operation @ The Historiotheque: how the world of the work is divided up, for describing, sorting, and retrieving it.

A schema is not a spec. A spec states how a kind of record must be made, and a document complies with it or does not; a schema states the facets along which works, projects, and materials are described, and it is applied, not complied with. Specs live in `new-documentation/specs/`; schemas live here.
