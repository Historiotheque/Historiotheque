# Bibliography — The Historiotheque

*Master bibliography of the art operation. Chicago Manual of Style, 17th edition.*

**Conventions**

- Entries use Chicago **author-date** (reference-list) format.
- Every entry gets a stable ID: `BIB-YYYY-NNN` (e.g. `BIB-2026-001`). IDs never change.
- Cite sources by ID from studio logs, Refcards, and design concepts.
- Project repos keep their own `BIBLIOGRAPHY.md` with the sources they actually use;
  this file is the master superset.
