# Prospectives

Prospectives are documents of possible futures for the Art Operation @ The Historiotheque: intentions, plans, and speculations, stated ahead of time.

A prospective is not a commitment and not a record. What actually happens is told by the record — the studio logs, the Official Releases, the Retrospectives. A prospective states what could happen, written from before it does or does not.

Prospectives are filed under dated filenames. When a prospective is superseded by events or by a later prospective, it stands as written; the later document supersedes it, and says so.
