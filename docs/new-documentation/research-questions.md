# Research Questions — Living Log

*Opened 2026-09-20. This is a working log, not a finished list: questions get added,
refined, split, answered, and superseded. Nothing here is final.*

**To add a question:** tell Oracle "add a research question" and state it. Oracle assigns
the next ID (`RQ-YYYY-NNN`), places it in a cluster (or starts a new one), and reads it
back for correction.

**Status values:** `open` · `refining` · `answering` (work underway) · `answered` ·
`superseded` (replaced by a better question — note which).
