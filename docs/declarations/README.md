# Declarations

Markdown conversions of the **Official Declarations of Production-Year**, originally published on Medium in [The Painter's Almanach](https://medium.com/the-painters-almanach), the publication of A.G.'s interdisciplinary art-research practice.

## Provenance

These files were converted from the Medium articles and reformatted for archival use: Medium's interface chrome (tags, byline blocks, clap/bookmark/listen buttons, share links) was removed, image URLs were normalized, and each file carries its source URL in a blockquote at the top. The Medium versions remain the canonical originals; these Markdown files are archival copies.

## Caveats

- **Link rot:** hyperlinks in these documents point to external sites (Medium, GitHub, WordPress, YouTube, and others) and may break over time as those sites change. This is expected and normal for archival copies.
- **Images:** images load remotely from Medium's CDN (`miro.medium.com`), so they depend on Medium's hosting remaining available.
- **Videos:** Markdown does not support embedded playable video, so videos appear as clickable thumbnails that link out to their YouTube pages. In a few files, the video embeds were missing from the source extraction and were restored from the author's earlier drafts at the positions indicated by the surrounding text.
