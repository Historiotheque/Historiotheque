# The Historiotheque v. 2.0.1 — summary

The Historiotheque is the name of the art studio: a modular workspace that houses the "Art Operations," a work-in-progress already 20+ years in the making. Version 2.0.1 is officially released on August 20, 2016.

The Historiotheque is a VISION of "The Perfect Workspace" for a contemporary interdisciplinary artist; the actual workspace is only ever the next "release" or "version" of that vision. Versions between 1.0 and the current release mostly happened at another location, and the Art Operations themselves stand at version 5.0.1, across 13 different locations over 20+ years — counting only the "official" releases.

Version 2.0.0 came out earlier in 2016, around the end of April, officially in the beginning of May; after a couple of months getting up and running in the new location, v2.0.1 marks roughly the 3-month anniversary of 2.0.0. Full documentation is promised in time.

A note appended to the release records corrections: semantic versions of different projects worked on within the same space had been confused, and keeping the projects separated in their versioning — possibly through a more modular, versatile inter-project versioning system — is flagged as the fix.
