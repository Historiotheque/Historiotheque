# First Unofficial Release of The Historiotheque: Soft Release v.5.0.0 — summary

May 2026. This Soft Release is the essential bridge between the legacy systems of the last thirty years and the anticipated arrival of a New Major Semantic Version. It was originally conceived in an unpublished draft in July 2025, and again following the "Quick Update" of September 2025, and remained intentionally held in the staging area. The Historiotheque has technically hovered at Minor Version 4.3.1, maintained through backward-compatible patches — but a total architectural shift is underway.

The operation resides in a state of "between-production": a deliberate suspension of the relaunch-shutdown cycle that governed it for over a decade. The daily cadence of creation remains — pixels are still moved, frequencies are still modulated — but public distribution entered a profound fallow season over the winter. This is framed as a "non-project project": operational continuity sacrificed, the non-production of the winter months becoming the primary data set for the upcoming v5.0.0 architecture.

The document sets the record straight on the versions that never were. The Quick Update of September 30, 2025 (quoted in full) had announced a shutdown effective June 7, 2025, and readiness to launch a new Major Version — misstated there as 4.4.1, a Minor Version. Version 4.4.1 was never officially launched. Instead, this Unofficial Release carries the Major Update as Semantic Version v5.0.0. Published here for the first time is the unfinished July 2025 draft of the Official Release 5.0.0 (MAJOR VERSION) — the relaunch text that was never sent, quoting 4.3.1's pledge that future releases would never break backward compatibility, with its features list left unwritten. That Major Version was never launched in 2025; the planned fall relaunch and the mentioned Minor Version were never fully documented; a long, liminal fallow winter followed.

Now the Major Version v5.0.0 is to be really worked on and published; details are reserved. The Soft Release / Soft Launch allows testing to continue in the background, while non-backward-compatible changes wait to be addressed, the quicker the better. The closing line: "It is a story of the Semantic Version MINOR VERSION 4.4.1 that never was. This Soft Release is its epitaph and a new beginning!"
