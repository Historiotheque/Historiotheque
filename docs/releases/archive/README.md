# Archive — full-text Official Releases

This folder holds the full texts of the Official Releases of the Historiotheque: the complete originals, in the author's voice, as published externally. Reader-facing summaries live one level up, in `releases/`.

Future full-text releases go here as well. Same filename as the summary (`YYYY-MM-DD-official-release-X.Y.Z.md`); the folder distinguishes the form.

## Reconstruction note (provisional wording — to be confirmed)

All past releases in this folder, up to and including the present publishing, are reconstructed from the author's collected texts. All future releases follow the Official Release Spec v1.0.
