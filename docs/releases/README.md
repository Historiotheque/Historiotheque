# Official Releases

*The Historiotheque releases like software — because it is software: cultural software, versioned with semantic versioning.*

## The Release as a design concept

The Historiotheque is the operator's art studio, sound design laboratory, and research space — and it is run as a versioned system. An Official Release marks a point in the life of the practice: a launch, a shutdown until further notice, a relaunch after a fallow period, a new season of work. Each release carries a semantic version number (MAJOR.MINOR.PATCH): MAJOR for rebuilds and relaunches that break with the past, MINOR for new directions inside a running operation, PATCH for fixes and refinements.

These are releases **of the practice itself** — not to be confused with the release notes of individual repositories, which live with their repos on GitHub.

## The two forms

- **Summaries** (this folder) — condensed, reader-facing summaries of each release's main points.
- **Full texts** (`archive/`) — the complete originals, in the author's voice, as published externally.

Both forms share the same filename; the folder tells you which form you are reading.
